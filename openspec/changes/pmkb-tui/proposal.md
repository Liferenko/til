## Why

Текущий метод ведения базы знаний в одном Markdown-файле не масштабируется: поиск через Vim (/) становится медленным при росте файла, сложно управлять метаданными, риск конфликтов при синхронизации между устройствами (Mac M4, ThinkPad T14, Android). Нужна локальная TUI-first система с мгновенным семантическим поиском и mesh-синхронизацией без зависимости от облачных сервисов.

## What Changes

- Создание TUI приложения на Python + Textual для управления базой знаний
- Реализация структуры хранения: отдельные Markdown файлы с YAML frontmatter в `~/kb/`
- Индексатор для автоматического обновления SQLite FTS5 базы при изменении файлов
- Интеграция с системным редактором ($EDITOR) для редактирования заметок
- Настройка mesh-синхронизации через Syncthing поверх Tailscale
- Поддержка работы на всех платформах: macOS, Linux, Android (через Termux)

## Capabilities

### New Capabilities

- `tui-interface`: Терминальный интерфейс с Vim-keybindings для навигации, поиска и управления заметками
- `search-engine`: Мгновенный полнотекстовый поиск по содержимому и метаданным через SQLite FTS5
- `file-indexer`: Мониторинг директории `~/kb/` и автоматическое обновление поискового индекса
- `mesh-sync`: Конфигурация и интеграция с Syncthing для P2P синхронизации базы между устройствами

## Impact

- Новый Python проект с зависимостями: `textual`, `sqlite3` (встроенный), `watchdog`
- Требуется настройка Syncthing на всех целевых устройствах (Mac M4, ThinkPad T14, Android)
- Требуется Tailscale для P2P связности между устройствами
- Миграция существующих заметок в новый формат (YAML frontmatter + Markdown)
- На Android требуется Termux с Python 3.12+
